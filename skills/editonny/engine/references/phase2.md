# Finishing an approved cut

After the current cut is verified, align word timing, establish the visual direction, build a representative sample, inspect it, then export. A later cut change invalidates dependent word timing and sound positions. Follow WORKFLOW.md for the single authoritative workflow.

See [WORKFLOW.md](../WORKFLOW.md) for scope, originals, source-language fidelity, and sample review.

## Helpers

Run the relevant helper with `--help` before supplying task-specific paths:

```sh
uv run --directory '<ENGINE>' python helpers/compose_final.py --help
uv run --directory '<ENGINE>' python helpers/quality_gate.py --help
```
