# Ready styles

Use the style catalog for consistent caption, hook, color, and audio settings. Start from the approved project style, then change only the requested properties. Preview actual words and the chosen font; a style name alone cannot establish readability.

See [WORKFLOW.md](../WORKFLOW.md) for scope, originals, source-language fidelity, and sample review.

## Helpers

Run the relevant helper with `--help` before supplying task-specific paths:

```sh
uv run --directory '<ENGINE>' python helpers/style_samples.py --help
uv run --directory '<ENGINE>' python helpers/text_render.py --help
```
