# Editing variations

Reuse a verified base cut and explicit changes for each variant. Vary the hook, duration, call to action, or visual direction only when requested. Preserve factual claims and source provenance. Give every output a distinct filename and recheck timing when the cut changes.

See [WORKFLOW.md](../WORKFLOW.md) for scope, originals, source-language fidelity, and sample review.

## Helpers

Run the relevant helper with `--help` before supplying task-specific paths:

```sh
uv run --directory '<ENGINE>' python helpers/assemble_cut.py --help
uv run --directory '<ENGINE>' python helpers/verify_cut.py --help
```
