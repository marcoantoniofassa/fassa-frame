# Direction by blocks

Plan blocks around complete ideas and measured source ranges. For each block record the spoken phrase, visual purpose, scene, caption behavior, supporting media, and sound cue. A visual change must not change what the speaker means. Revalidate timing whenever the underlying cut changes.

See [WORKFLOW.md](../WORKFLOW.md) for scope, originals, source-language fidelity, and sample review.

## Helpers

Run the relevant helper with `--help` before supplying task-specific paths:

```sh
uv run --directory '<ENGINE>' python helpers/align_words.py --help
uv run --directory '<ENGINE>' python helpers/filmstrip.py --help
```
