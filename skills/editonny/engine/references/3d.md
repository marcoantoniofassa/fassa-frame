# 3D scenes

Use the pinned local Three.js resources in the project template. Real geometry, light, camera, and occlusion justify a 3D label; flat layers with parallax are 2.5D. Keep render timing deterministic and validate model, texture, font, and module paths before export.

See [WORKFLOW.md](../WORKFLOW.md) for scope, originals, source-language fidelity, and sample review.

## Helpers

Run the relevant helper with `--help` before supplying task-specific paths:

```sh
uv run --directory '<ENGINE>' python helpers/filmstrip.py --help
```
