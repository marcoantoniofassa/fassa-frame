# Empty Set prompts

Replace bracketed details with the actual subject and scene. Preserve the identity, framing, motion and lighting constraints. Request a cost estimate and obtain authorization before generation. Model settings, observed limitations and assembly steps are in [README.md](README.md).

## 1. Remove the person

```
Remove the [man] completely from this photo and reconstruct the empty room behind him exactly: same walls, same [line-art face painting], same [hallway, floor, rug, lights, furniture and objects], same camera position, perspective, framing, lighting and colors. Photorealistic, nothing added, no person.
```

## 2. Remove the person while retaining spotlight lighting

```

Keep the same camera framing, same darkness, and the same [white volumetric spotlight cone from the ceiling with dust particles], now landing as a soft bright pool of light where he was sitting. ```

```

Repaint ONLY that blurry patch as the natural, sharp, photorealistic continuation of this same room: [expected missing details: the white wall corner with the thin vertical white pipe, the plant continuing down to its terracotta pot, the light wood floor with soft window reflections, the white sofa and the pink cushion]. Same daylight, same lens, same colors, same grain. Keep everything else in the room pixel-identical: [existing sharp details: the ceiling beam, the track lights, the painting, the big window]. Do not add any person, furniture or new object. Same framing, no crop, no zoom.
