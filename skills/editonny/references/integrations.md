# Optional integrations

The standard engine uses local Python, FFmpeg, Whisper, and the project's pinned HyperFrames version. An available plugin is not proof that it is installed, connected, compatible, or authorized to spend credits.

- **HyperFrames:** retain the project pin. Validate changes with lint, check, snapshots, rendering, audio inspection, and backward seeking; reading documentation alone does not prove compatibility.
- **Anatomy:** an optional source of explanatory isometric SVG/HTML. Integrate an original short scene when its mechanism clarifies the speech. Animation state must depend on frame/time and remain correct when seeking out of order. There is no built-in adapter.
- **Remotion:** an external option for parameterized React video, not a dependency of this package. Its own license applies; do not assume it is MIT or universally free.
- **Shotcut or Kdenlive:** optional manual finishing of exported MP4. Layers are flattened; editonny does not export editable timelines for these applications.
- **External media generation:** use only when required by the request and authorized for the stated cost and transmitted inputs. Explain the service, supplied media, available estimate, and sample before execution. Never put secrets into prompts or documentation queries.

Prefer an existing scene, an original code composition, or authorized supplied media. Do not copy entire plugins to expand the catalog. Do not promise platform approval, ownership of third-party media, domain availability, or an untested effect.

First-party editonny code is MIT licensed; dependencies and media keep their own licenses and notices. In the complete checkout, [the integration reference](../../../docs/integrations.md) records the development policy. A standalone skill may omit development-only documents; this page contains the operational guidance it needs.
