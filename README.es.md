# Fassa Frame

Edición de vídeo mediante conversación, basada en Editonny de Matheus Gomes y adaptada por Marco Fassa. Esta distribución inicial tiene documentación de bienvenida en portugués; el código y los contratos internos conservan sus nombres originales.
