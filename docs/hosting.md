# Guia no navegador

O código do guia fica em `web/`. Esta distribuição não cria um site público nem inclui configuração de conta de hospedagem.

Para usar localmente, siga [installation.md](installation.md). Uma eventual implantação deve usar o checkout e a conta autorizados para esse trabalho, sem copiar caminhos pessoais nem configurações de outros sites.

O exportador `scripts/export-web.mjs` é um recurso de manutenção herdado. Antes de usá-lo, confira o destino, a configuração e as instruções atuais do ambiente. Criar o repositório não autoriza publicar um site.
